# GitHub Collabo

HTML과 GitHub 협업을 연습하기 위한 간단한 연락처 페이지 프로젝트입니다.

## 프로젝트 소개

사용자가 이름, 이메일, 연락처, 문의 내용을 입력할 수 있는 연락처 양식을 제공합니다. 페이지 하단에는 회사 주소와 연락처 정보가 표시됩니다.

## 현재 구현된 내용

- 연락처 입력 페이지 추가
- 이름, 이메일, 연락처, 문의 내용 입력 항목 제공
- 회사 주소, 전화번호, 이메일 정보 표시
- 회사 주소 및 전화번호 최신 정보 반영

현재는 HTML 화면만 구현되어 있으며, 문의 내용을 실제로 전송하는 백엔드 기능은 포함되어 있지 않습니다.

## AAA 브랜치 작업 내역

- `contact.html` 연락처 페이지 생성
- 이름, 이메일, 연락처, 문의 내용 입력 양식 구현
- 회사 주소를 경기도 화성시 동탄구로 변경
- 회사 전화번호를 `031-123-4567`로 변경

## 실행 방법

별도의 설치 과정 없이 `contact.html` 파일을 브라우저에서 열어 확인할 수 있습니다.

```bash
open contact.html
```

## 파일 구조

```text
.
├── contact.html  # 연락처 페이지
└── README.md     # 프로젝트 문서
```

## 협업 흐름

1. `main` 브랜치에서 최신 변경 사항을 pull 합니다.
2. 작업 목적에 맞는 브랜치를 생성합니다.
3. 변경 사항을 커밋하고 원격 저장소에 push 합니다.
4. Pull Request를 생성해 리뷰 후 `main`에 병합합니다.
팀 소개와 협업 철학을 담은 정적 웹페이지 프로젝트입니다.

## 프로젝트 소개
이 프로젝트는 사용자 중심의 서비스 기획과 협업 문화를 강조하는 팀 소개 페이지를 만드는 데 목적이 있습니다. 팀의 가치관, 미션, 핵심 원칙, 연락처 정보를 한눈에 볼 수 있도록 구성했습니다.

## 주요 내용
- 팀 소개 및 프로젝트 철학 설명
- 팀의 핵심 가치 정리
- 미션과 협업 방식 소개
- 연락처 정보 표시

## 기술 스택
- HTML5
- CSS 없음 (단순 정적 페이지 구성)
- 브라우저에서 바로 열 수 있는 구조

## 프로젝트 구조
```text
github-collabo/
├── about.html     # 팀 소개 페이지
├── README.md      # 프로젝트 문서
└── .gitignore     # 필요 시 추가
```

## 실행 방법
1. 저장소를 로컬에 클론합니다.
2. 브라우저에서 `about.html` 파일을 직접 엽니다.
3. 또는 로컬 서버를 실행해 확인할 수 있습니다:

```bash
python -m http.server 8000
```

그다음 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000/about.html
```

## 협업 목표
- 사용자 경험을 최우선으로 생각하기
- 서로의 아이디어를 존중하며 협업하기
- 문제를 명확히 정의하고 해결책을 실용적으로 구현하기
- 지속 가능한 성장과 개선을 추구하기

## GitHub 협업 규칙
- `main` 브랜치에서 최신 내용을 pull 받아 작업 시작
- 기능별 브랜치를 생성해 작업
- 의미 있는 커밋 메시지 작성
- PR을 통해 변경 사항 검토 후 병합

## 팀 원칙
- 사용자 중심의 생각
- 꾸준한 협업과 소통
- 명확한 문제 해결
- 지속 가능한 성장
