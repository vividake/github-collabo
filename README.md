# GitHub Collabo

팀 소개와 협업 철학을 담은 정적 웹페이지 프로젝트입니다.

## 프로젝트 소개
이 프로젝트는 사용자 중심의 서비스 기획과 협업 문화를 강조하는 팀 소개 페이지를 만드는 데 목적이 있습니다. 팀의 가치관, 미션, 핵심 원칙, 연락처 정보를 한눈에 볼 수 있도록 구성했습니다.

## 주요 내용
- 팀 소개 및 프로젝트 철학 설명
- 팀의 핵심 가치 정리
- 미션과 협업 방식 소개
- 연락처 정보 표시

## 기술 스택
- HTML5
- CSS 없음 (단순 정적 페이지 구성)
- 브라우저에서 바로 열 수 있는 구조

## 프로젝트 구조
```text
github-collabo/
├── about.html     # 팀 소개 페이지
├── README.md      # 프로젝트 문서
└── .gitignore     # 필요 시 추가
```

## 실행 방법
1. 저장소를 로컬에 클론합니다.
2. 브라우저에서 `about.html` 파일을 직접 엽니다.
3. 또는 로컬 서버를 실행해 확인할 수 있습니다:

```bash
python -m http.server 8000
```

그다음 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000/about.html
```

## 협업 목표
- 사용자 경험을 최우선으로 생각하기
- 서로의 아이디어를 존중하며 협업하기
- 문제를 명확히 정의하고 해결책을 실용적으로 구현하기
- 지속 가능한 성장과 개선을 추구하기

## GitHub 협업 규칙
- `main` 브랜치에서 최신 내용을 pull 받아 작업 시작
- 기능별 브랜치를 생성해 작업
- 의미 있는 커밋 메시지 작성
- PR을 통해 변경 사항 검토 후 병합

## 팀 원칙
- 사용자 중심의 생각
- 꾸준한 협업과 소통
- 명확한 문제 해결
- 지속 가능한 성장
